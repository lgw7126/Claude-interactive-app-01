## 기획 의도

호쿠사이의 우키요에 「가나가와 해변의 높은 파도(神奈川沖浪裏)」를 포트폴리오 첫 화면(히어로 섹션)으로 쓰기 위해 만든 인터랙티브 페이지입니다.

일반적인 파티클/캐릭터가 마우스를 따라다니는 인터랙션(예: 새·물고기 무리가 커서를 쫓아다니는 연출)에서 착안했지만, 이 작품은 그림 자체가 "파도"이기 때문에 **캐릭터를 얹는 대신 파도 그림 자체가 손짓에 반응해 출렁이도록** 방향을 바꿨습니다.

가장 중요하게 지킨 원칙은 하나입니다.

> **원작의 화풍과 색감은 절대 수정하지 않는다.**

그래서 새로운 그래픽을 그리거나 필터를 씌우는 대신, 원본 판화의 **픽셀 위치만 물리적으로 왜곡(displacement)**시키는 방식을 택했습니다. 색상 값 자체는 원본 이미지에서 그대로 샘플링되므로, 화면이 아무리 출렁여도 붓 터치·먹색·전통 안료 톤은 원작 그대로 유지됩니다. 하늘과 후지산은 정적인 배경으로 남겨 두어, 오직 "파도"라는 그림의 주제만 살아 움직이게 했습니다.

## 사용 방법

### 1) 바로 체험하기
위 **[지금 바로 실행해보기]** 링크를 클릭하면 별도 설치 없이 브라우저에서 바로 열립니다.

### 2) 조작법

| 입력 | 효과 |
|---|---|
| 마우스 이동 (또는 터치 드래그) | 움직인 방향으로 파도가 솟구치고 잔물결이 퍼져나감 |
| 클릭 / 탭 | 그 지점에서 물이 크게 출렁이는 스플래시 효과 |
| 화면 우하단 **✋ 손 추적 켜기** 버튼 | 웹캠 권한을 허용하면, 검지 손끝의 움직임으로 파도를 조종. 처리는 전부 브라우저 안에서만 이뤄지며(MediaPipe, 로컬 실행) 영상이 외부로 전송되지 않음 |
| 카메라 거부/미지원 | 자동으로 마우스 조작 모드로 전환 (에러 없이 계속 사용 가능) |

가만히 두어도 바다가 은은하게 숨 쉬듯 잔물결이 이는 상시 애니메이션이 있습니다.

### 3) 내 컴퓨터에서 직접 열어보기

정적 파일이므로 별도 빌드 없이 서버만 띄우면 됩니다.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

### 4) 내 GitHub Pages로 배포하기

리포 **Settings → Pages** 에서 Source를 "Deploy from a branch"로 두고, 이 브랜치(또는 main에 합친 뒤 `main`)와 `/ (root)` 폴더를 선택하면 몇 분 안에 고유 주소로 배포됩니다.

```html
  ...

```

### 파도 세기 조절
`index.html`의 프래그먼트 셰이더 안 계수를 조절하면 됩니다.

- `ampMouse` — 마우스 이동에 반응하는 세기
- `ampSplash` — 클릭 시 스플래시 세기
- `0.0026` / `0.0014` — 가만히 있을 때 상시 잔물결 세기

## 파일 구성

- `index.html` — 페이지 전체 (CSS/JS/WebGL 셰이더 단일 파일, 외부 라이브러리 없음. 손 추적 사용 시에만 MediaPipe를 CDN에서 불러옴)
- `assets/wave.jpg` — 원본 판화 (워터마크 제거 + AI 초해상도 4배 업스케일, 3292×2104)
- `assets/mask.png` — 파도 영역만 표시한 마스크 (흰 부분만 움직이고, 하늘·후지산은 고정)
